# 해솔력테스트 빠칭코 v13

## 변경 사항
- STOP 하트를 보라색 둥근 네모 패널 안에 배치
- STOP 하트는 테두리 없이 더 통통하고 입체적인 SVG 하트로 변경
- 하트 끝부분을 둥글고 부드럽게 조정
- STOP 위 장식 하트를 초록·노랑·핑크·보라 4개로 변경
- 장식 하트를 위아래로 물결치듯 배치하고 파스텔 톤 적용
- 기존 레버 → 회전 → STOP → 퀴즈 출제 흐름과 50문제는 그대로 유지
