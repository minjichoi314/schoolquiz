# 배곧해솔중학교 해솔력테스트 퀴즈 v9

공을 뽑는 데 성공하면 명언 대신 배곧해솔중학교 4지선다 퀴즈가 나타나는 버전입니다.

## 기능
- 파스텔 크레인 게임 디자인
- 공 20개
- 초록: 왼쪽 / 빨강: 오른쪽 / 파랑: 위 / 노랑: 아래
- 보라색 GRAB 버튼
- 공 뽑기 성공 시 50문제 중 한 문제가 랜덤 출제
- 오답은 다시 선택 가능
- 정답을 맞히면 게임으로 돌아가기 버튼 표시
- 50문제를 한 번씩 섞어서 출제한 뒤 다시 셔플

## GitHub Pages
`index.html`, `style.css`, `app.js`를 저장소 루트에 업로드하면 됩니다.
